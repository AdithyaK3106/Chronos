Core Innovation

Chronos changes the unit of coordination.

TRADITIONAL APPROACH

File-Level Locking

Entire file is locked when an agent edits any line.

📄 auth.py (FULL FILE LOCKED)
Agent A → authenticate_user() LOCKED
Agent B → refresh_token() BLOCKED
logout() BLOCKED

❌ Result: Agent B is completely blocked from modifying unrelated code.

CHRONOS APPROACH

Sub-File AST Node Locking

Agents lock specific AST nodes (functions/classes) via intent ledger.

📄 auth.py (AST GRANULAR LOCKS)
Agent A → authenticate_user() LOCKED BY A
Agent B → refresh_token() LOCKED BY B
logout() AVAILABLE

✓ Result: Zero unnecessary blocking. Agents modify unrelated nodes concurrently.
